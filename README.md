## Solutions
### Dynamic Pseudo-partitioning of queries in Dataflows
According to Roche's Maxim of Data Transformation, "Data should be transformed as far upstream as possible, and as far downstream as necessary". This idea stemmed in the need to optimized the query workload of data coming SAP BW data source. I didn't have access to the upstream data source in the SAP BW. This approach led to better query workload and refresh of dataflows by creating multiple partition of data using the Dataflows. Thus achieving the pseudo-partitioning of queries in dataflows much like the principle in table partitioning in the Database Management Systems. This approach is reusable for various users that are stucked with query refresh issues within their dataflows or datasets. 

### Leveraging Power BI REST API in Power BI Content Governance
Power BI service empowers users to programmatically maintain and govern Power BI contents across workspaces and with multiple workstream users. The idea stemmed in the need to have a centralized governance and maintenance of all Power BI contents without having an elevated tenant admin access. Power BI has a wide-range of endpoints to use from. I use Power Automate to automate that workflows to gather specific data from those endpoints and Power Apps to create a business application for that workflow. 

### Real-time commenting for Power BI Reports using Power Apps
This solution empowers users to not just view reports in Power BI but also interact with the data and input their comments within the data. Power BI didn't have features on commenting to a certain data from various users and storing it for later viewing.
